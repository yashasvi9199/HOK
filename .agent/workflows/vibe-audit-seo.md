# SEO Compliance Audit Task

1. Scan all page routes to ensure unique `<title>`, `<meta name="description">`, and `<link rel="canonical">` tags exist.
2. Verify that indexable landing views render valid JSON-LD structured data.
3. Check headings for strict unbroken hierarchy (single H1 per page, sequential H2/H3).
4. Inspect all `<img>` tags for descriptive, non-empty `alt` text and explicit width/height dimensions.
5. Print a structured pass/fail compliance checklist with file links.
